# Design references and third-party notices

ChronoFlip is an original MIT-licensed implementation. It has no
third-party runtime packages, remote fonts, or copied visual assets.

The optional **Classic Weather** display style was created as a clean-room
interpretation of the broad retro pattern of two large flip-clock panels above
a weather console. These open-source projects were useful visual references:

- [iamBiB/lovelace-htc-flipclock-weather](https://github.com/iamBiB/lovelace-htc-flipclock-weather) — its README describes the project as MIT licensed. Its source code, bundled images, names, and branding are not included here.
- [pruefsumme/plasma-flipclock](https://github.com/pruefsumme/plasma-flipclock) — licensed AGPL-3.0-or-later. Its QML, artwork, fonts, and source code are not included here.
- [AlynxZhou/flipclock](https://github.com/AlynxZhou/flipclock) — licensed Apache-2.0. Its responsive paired-card composition was a visual reference for the independently implemented Slate Cards clock face. Its C/SDL source, font, binaries, and artwork are not included here.

The clock panels, layout, animation, controls, and inline SVG weather symbols
in this project were independently implemented for this dashboard.
